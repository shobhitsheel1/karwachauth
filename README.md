# Karwa Puzzles

A tap-to-reveal rebus quiz on Karwa Chauth: the vrat, the katha, the moon and solah shringar, with warm-ups, hints and a scoreboard. Six warm-ups, then 38 puzzles on Karwa Chauth: sargi, mehendi, the katha, the moon and more.

**Play:** open the GitHub Pages link on your phone, then use Share → Add to Home Screen to get it as an app.
Turn the phone sideways for the TV layout. Tap **Right** or **Wrong** after each guess; swipe to move between puzzles.
